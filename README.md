📌 Overview
This project is a modified version of the **starter template provided by Wells Fargo** for Task 2 of their Software Development Forage program.  
I cloned the original repository and enhanced it with improved file reading functionality, added documentation, and optimized code for better readability and usability.

🗂️ Project Structure
WellsFargo_Task2/
│── data/
│   └── sample_data.txt                  # Example input file
│── src/
│   ├── FileReader.java                  # File reading utility
│   ├── Main.java                        # Main program
│── tests/
│   └── FileReaderTest.java              # Unit tests
│── README.md
│── requirements.txt                     # Optional dependencies
│── .gitignore

🛠️ Technologies Used
Java 11+
Maven (for building and running)
JUnit (for unit testing)
